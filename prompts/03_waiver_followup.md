# Waiver Follow-up

Read the actual post-processing roster, pending claims, recent transactions, current available-player pool, remaining budget, and waiver order. Do not infer success from a previously recommended claim, a clock time, or a delivered report.

Separate claims into confirmed successful, confirmed unsuccessful, and still pending. If processing has not completed, report that fact and request a later read rather than treating the claim as lost. Reconcile any execution receipts against ESPN; ESPN's current verified state governs.

Determine which previously identified needs remain unmet. Re-rank only the still-available alternatives, verify the current acquisition mechanism, and compare each remaining move with doing nothing. Consider newly dropped players, but verify their own waiver deadlines before calling them immediately available.

Return exact fallback recommendations with valid add/drop pairings, changed spending limits where applicable, and a short list of decisions now obsolete. Do not repeat a completed move or continue recommending a player who now belongs to another team. Route changed lineup consequences into the next consolidated report.
